# data/

Lexical and morphological comparanda. Not yet populated.

Every form recorded here carries a `provenance` field:

- `cited` — with the work and page or entry number where the form is attested
  or glossed (e.g. Soysal 2004, p. N);
- `uncollated` — entered without having been checked against a published
  source.

An empty slot is left empty. No form is reconstructed, guessed, or supplied
from memory to fill a gap.
